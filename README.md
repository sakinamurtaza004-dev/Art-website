# Art & Craft Website

Portfolio + shop for artwork and handmade crafts, with a customisation request option.

## Structure

```
art-website/
├── index.html              Home (to be built)
├── pages/                  Gallery, product detail, customise, about, contact
├── css/                    Stylesheets
├── js/                     Scripts (gallery filter, customisation form)
├── data/
│   ├── products.json       All artworks/crafts (edit this to add items)
│   └── customisation-options.json   Customisation form options
├── assets/
│   ├── images/{artworks,crafts,about,hero}
│   ├── icons/
│   └── fonts/
├── reference/              Drop reference site screenshots/links here
└── docs/                   Notes, brand guidelines, content checklist
```

## Planned pages
1. Home – hero, featured work, categories, about teaser
2. Gallery / Shop – filterable listing of artworks and crafts
3. Product detail – images, details, enquire / customise button
4. Customise – request form (type, size, idea, reference images, deadline)
5. About – artist story
6. Contact
